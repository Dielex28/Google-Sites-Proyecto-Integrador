# Lista para armar el sitio en Google Sites

Todo lo necesario, en orden, con enlaces directos. Hazlo en una **computadora** con
Chrome o Edge: el editor de Google Sites no funciona bien en el celular. Calcula
unos 40 minutos.

Cada enlace de **código** abre el archivo en GitHub: usa el botón **Copy raw file**
(ícono de dos hojas, arriba a la derecha del archivo) para copiarlo completo. Cada
enlace de **imagen** abre la foto: usa **Download raw file** (flecha hacia abajo) para
descargarla.

---

## Paso 1 · Crear el sitio (5 min)

- [ ] Entra a **sites.google.com** → **Sitio en blanco**.
- [ ] Arriba a la izquierda escribe el nombre: **Mapa del Semestre 1A**.
- [ ] Panel derecho → **Temas** → **Simple** → color personalizado **#3B5BFF**.
- [ ] Descarga el [logotipo](https://github.com/Dielex28/Google-Sites-Proyecto-Integrador/blob/ccr-f9886f39-gopzg4/google-sites/imagenes/logo-1A.png).
  Pasa el cursor sobre el nombre del sitio → **Agregar logotipo** → súbelo.
- [ ] **Configuración** (engrane) → **Marca** → **Favicon** → sube el mismo logotipo.

## Paso 2 · Crear todas las páginas (5 min)

Panel derecho → pestaña **Páginas** → botón **+**. Crea en este orden:

- [ ] Inicio *(ya existe; si se llama "Página principal", cámbiale el nombre)*
- [ ] Materias
- [ ] Tutoría de Ingreso I
- [ ] Tecnologías de la Información
- [ ] Sexualidad y Perspectiva de Género
- [ ] Programación Básica
- [ ] Inglés Básico
- [ ] Historia e Identidad Universitaria
- [ ] Habilidad Numérica
- [ ] Habilidad de Lectoescritura
- [ ] Física y sus Aplicaciones
- [ ] Educación Socioemocional
- [ ] Calendario
- [ ] Equipo

Luego arrastra cada una de las 10 materias **encima** de "Materias" para que queden
como subpáginas (aparecen con sangría).

## Paso 3 · Llenar cada página (30 min)

**Cómo pegar un bloque** (se repite cada vez):

1. Abre el enlace del bloque → **Copy raw file**.
2. En Google Sites: **Insertar** → **Incorporar** → pestaña **Insertar código** →
   pega (**Ctrl + V**) → **Siguiente** → **Insertar**.
3. Estira el cuadro de lado a lado hasta ocupar **todo el ancho**.
4. Estira el borde inferior hasta la **altura** indicada (o hasta que no haya barra de
   desplazamiento dentro del cuadro).

**Cómo poner el encabezado:** pasa el cursor sobre el encabezado de la página →
**Cambiar imagen** → **Subir** → elige la foto → **Tipo de encabezado: Banner**.

## Paso 4 · Datos del equipo

Puedes pegar el bloque de Equipo tal cual y completar los datos después. Para
completarlos: selecciona el bloque en Google Sites → ícono de **lápiz** (Editar código)
→ busca **✏️ DATOS DEL EQUIPO** (casi al principio) → llena los datos **entre las
comillas** → **Siguiente** → **Insertar**.

Cada integrante es un renglón como este:

```js
{ nombre: "David López Martínez", codigo: "226012345", correo: "david.lopez@alumnos.udg.mx", rol: "Diseño y contenido", frase: "Me gusta programar videojuegos", foto: "" },
```

Datos que necesitas de cada uno:

| Integrante | Nombre completo | Código de alumno | Correo | Rol en el equipo | Frase o pasatiempo |
|---|---|---|---|---|---|
| David | | | | | |
| Alan | | | | | |
| Armando | | | | | |
| Isaac | | | | | |
| Diego | | | | | |
| Uziel | | | | | |

- Lo que dejes vacío (`""`) aparece como "Por completar".
- `foto` necesita un enlace público a una imagen cuadrada; si lo dejas vacío salen las
  iniciales.
- No borres las comas ni las llaves `{ }`.

## Paso 5 · Revisar y publicar

- [ ] Botón **Vista previa** (ícono de pantalla) y revisa cada página; prueba también la
  vista de celular.
- [ ] Si un cuadro muestra una barra de desplazamiento, hazlo más alto.
- [ ] **Publicar** → dirección web, por ejemplo `mapa-semestre-1a`.
- [ ] En **Quién puede ver mi sitio** elige quién puede abrirlo (por ejemplo, cualquier
  persona con el enlace).
- [ ] **Compartir con otros** (persona con +) → agrega los correos del equipo como
  **Editores** si quieren que también puedan editar.
- [ ] Copia el enlace publicado y compártelo con su profesor o profesora.
