### Ejemplo: así se ve un algoritmo en PSeInt

```
Algoritmo PromedioParcial
    Definir c1, c2, c3, prom Como Real
    Escribir "Captura tres calificaciones:"
    Leer c1, c2, c3
    prom <- (c1 + c2 + c3) / 3
    Si prom >= 60 Entonces
        Escribir "Aprobado con ", prom
    SiNo
        Escribir "Reprobado con ", prom
    FinSi
FinAlgoritmo
```

Ejemplo ilustrativo: lee tres calificaciones, calcula el promedio y decide si se aprueba con 60 o más. Usa estructura secuencial y selectiva.
